*Storage Estimator - Feature Version*



Purpose:

This Python program accepts a storage size in gigabytes and converts it into megabytes, kilobytes, bytes, and terabytes.



Requirements:

\- Python 3



How to Run:

Open a terminal in the project folder and run:

**py storage\_estimator.py**



Enter the storage size in gigabytes when prompted.



Example:

Input: 2



Expected output:

\- Storage in MB: 2048.0

\- Storage in KB: 2097152.0

\- Storage in bytes: 2147483648.0

\- Storage in TB: 0.001953125
